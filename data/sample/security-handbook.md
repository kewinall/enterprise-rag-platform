# Identity and Access

Administrative access should use least privilege and individual identities. Shared credentials should be avoided, and privileged actions should be auditable.

# Document Security

Documents used by retrieval systems should be treated as untrusted input. Uploads should be scanned, access-controlled, and retained according to policy.

# Model Governance

Production model endpoints should be allowlisted. Model changes should be evaluated for quality, latency, cost, and security before release.

# v0.3 功能指南 / v0.3 Feature Guide

## 1. RAGAS-style Answer Evaluation

**繁體中文**  
v0.3 新增 LLM-as-a-Judge Evaluator，可針對 Question、Answer、Retrieved Context 與 Optional Reference 計算 Faithfulness、Answer Relevance、Context Relevance、Answer Correctness。

**English**  
v0.3 adds an LLM-as-a-Judge evaluator for question, answer, retrieved contexts, and an optional reference answer. It scores faithfulness, answer relevance, context relevance, and answer correctness.

API:

    POST /api/v1/evaluate/answer

CLI:

    make evaluate-answers

## 2. OpenTelemetry

**繁體中文**  
Trace 會涵蓋 HTTP Request、Retrieval、RAG Orchestration、LLM Completion 與 Evaluation。Prompt、Context、Answer Body 不寫入 Span Attribute。

**English**  
Traces cover HTTP requests, retrieval, RAG orchestration, LLM completion, and evaluation. Prompt, context, and answer bodies are not written to span attributes.

## 3. PostgreSQL Audit

**繁體中文**  
Application Startup 會建立 rag_audit_event Table。每個 HTTP Request 記錄 Request ID、Method、Path、Status、Duration 與低敏 Metadata。

**English**  
Application startup creates the rag_audit_event table. HTTP requests record request ID, method, path, status, duration, and low-sensitivity metadata.

## 4. Redis Cache

**繁體中文**  
RAG Answer Cache Key 由 Question、Top-K、Retrieval Mode、Filters、Model 產生。Cache Miss 才會進行 Retrieval 與 LLM Generation。

**English**  
The RAG answer cache key is derived from question, top-k, retrieval mode, filters, and model. Retrieval and generation run only on cache misses.

## 5. LiteLLM Gateway

**繁體中文**  
FastAPI 只認 OpenAI-compatible Endpoint。預設 LiteLLM 將 enterprise-rag Model Route 到 Ollama 的 llama3.2:3b，可替換為其他 Model Provider。

**English**  
FastAPI only depends on an OpenAI-compatible endpoint. The default LiteLLM configuration routes enterprise-rag to Ollama llama3.2:3b and can be replaced with other providers.

## 6. Web UI

**繁體中文**  
首頁提供無外部 CDN 的單頁 Demo UI，支援 API Key Session、Multi-file Upload、Document List、Vector / Hybrid Chat 與 Citation Inspection。

**English**  
The root page serves a single-page demo UI with no external CDN dependency, supporting API-key session storage, multi-file upload, document listing, vector/hybrid chat, and citation inspection.

## Scope Boundary / 範圍界線

v0.3 尚未處理 / does not yet include:

- OIDC / Enterprise SSO
- Multi-tenancy
- MinIO / S3 Object Storage
- Kubernetes / Helm
- Secret Manager
- Production Trace Backend such as Tempo / Jaeger

# v0.5 功能指南 / v0.5 Feature Guide

## Overview / 概覽

**繁體中文**  
v0.5 將平台從 Enterprise RAG Platform 推進到 Agentic AI Platform Reference Architecture，同時保留 v0.4 的身份、租戶、安全、部署與離線能力。

**English**  
v0.5 evolves the project from an enterprise RAG platform into an Agentic AI platform reference architecture while retaining the v0.4 identity, tenancy, security, deployment, and offline capabilities.

## Delivered / 完成項目

1. Agentic RAG State Machine
2. Query Planner / Rewrite
3. Multi-hop Retrieval
4. Context Sufficiency Critic
5. Corrective Retrieval
6. Answer Critic
7. Optional Answer Revision
8. Tool Registry
9. Tool Permission Policy
10. Human Approval Gate
11. Redis Approval TTL
12. Approve / Reject API
13. Agent Execution Trace
14. Agent Evaluation
15. Standard RAG / Agentic RAG Web UI
16. Helm / Offline Version Update

## API

    GET  /api/v1/agent/tools
    POST /api/v1/agent/query
    GET  /api/v1/agent/approvals/{action_id}
    POST /api/v1/agent/approvals/{action_id}/approve
    POST /api/v1/agent/approvals/{action_id}/reject
    POST /api/v1/agent/evaluate

## Example Agent Query

    {
      "question": "Compare our production release and security requirements.",
      "top_k": 5,
      "mode": "hybrid"
    }

Response contains:

- status
- answer
- citations
- plan
- review
- trace

## Destructive Action

若 User 要求刪除文件且 Planner 有已知 document_id，Agent 會提出 delete_document。  
If the user requests document deletion and the planner has a known document_id, it may propose delete_document.

Agent 不會直接刪除；Response 會是：

    status = awaiting_approval

Admin 必須另外呼叫 Approval API。  
An Admin must separately call the approval API.

## Compatibility

**繁體中文**  
既有 Standard RAG API、Document API、OIDC/RBAC、Tenant Isolation、Object Storage、Docker Compose、Helm 與 Offline Bundle 都保留。

**English**  
Existing Standard RAG APIs, document APIs, OIDC/RBAC, tenant isolation, object storage, Docker Compose, Helm, and offline bundles remain available.

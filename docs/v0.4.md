# v0.4 功能指南 / v0.4 Feature Guide

## Overview / 概覽

**繁體中文**  
v0.4 將專案從「可觀測的 Enterprise RAG Runtime」推進到具備 Identity、Tenant Isolation、Object Storage、Kubernetes Delivery 與 Air-Gapped Deployment 的 AI Platform Reference Architecture。

**English**  
v0.4 evolves the project from an observable enterprise RAG runtime into an AI platform reference architecture with identity, tenant isolation, object storage, Kubernetes delivery, and air-gapped deployment.

## Delivered / 完成項目

1. OIDC JWT Validation
2. Viewer / Editor / Admin RBAC
3. Server-enforced Multi-tenancy
4. Tenant-scoped Qdrant Metadata and Document IDs
5. Tenant-scoped Redis Cache + Revision Invalidation
6. MinIO / S3 Original Document Storage
7. Presigned Document Download
8. Optional Keycloak Demo Realm
9. Kubernetes Helm Chart
10. HPA / PDB / NetworkPolicy / SecurityContext
11. External Secret Integration Example
12. Offline Bundle Scripts
13. CI Validation for Compose / Helm / Keycloak / Shell Scripts

## Upgrade Note / 升級注意

**繁體中文**  
v0.3 已存在的 Qdrant Chunk 沒有 tenant_id，因此升級 v0.4 後不會被任何 Tenant 查詢到。請重新 Ingest 原始文件，讓 Chunk 取得新的 Tenant Metadata；不要直接把舊資料硬指定到任意 Tenant。

**English**  
Chunks created by v0.3 do not contain tenant_id and therefore are not visible to any tenant after upgrading to v0.4. Re-ingest original documents so chunks receive the correct tenant metadata; do not arbitrarily assign legacy data to a tenant.

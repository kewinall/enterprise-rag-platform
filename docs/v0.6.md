# v0.6 功能指南 / v0.6 Feature Guide

## Overview / 概覽

**繁體中文**  
v0.6 將 v0.5 的單次 Agentic RAG Runtime 推進成具備 Durable State、Async Jobs、Governed Memory、MCP Tool Adapter、Budget/Rate Control 與 Agent Observability 的 Enterprise Agent Platform。

**English**  
v0.6 evolves the v0.5 single-request Agentic RAG runtime into an enterprise agent platform with durable state, async jobs, governed memory, an MCP tool adapter, budget/rate controls, and agent observability.

## Delivered / 完成項目

1. PostgreSQL Agent Session
2. Durable Checkpoint
3. Durable Async Job Queue
4. Restart Recovery for running jobs
5. Explicit Session Memory
6. Memory Retention / Expiration
7. Tenant-scoped Read-only Data Platform Tools
8. MCP-compatible Tool Adapter
9. 2026-07-28 modern discovery + 2025-11-25 legacy initialize subset
10. Token Budget Enforcement
11. Estimated Cost Budget
12. Redis Agent Rate Limit
13. Prometheus Agent Metrics
14. Grafana Agent Dashboard JSON
15. Expanded Prompt / Tool Injection Evaluation
16. Web UI for Session / Memory / Async Job

## Durable Flow / 持久化流程

    Session
      |
      +--> Memory (TTL)
      |
      +--> Agent Run
              |
              +--> Budget
              +--> Tools
              +--> Answer
              |
              v
         Checkpoint

    Async Request
      |
      v
    PostgreSQL Job: queued
      |
      v
    Worker: running
      |
      v
    completed / failed

Application restart 時，running Job 會重設為 queued 再由 Worker 接續。  
On application restart, running jobs are returned to queued state for recovery.
